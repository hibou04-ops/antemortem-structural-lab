## 순증분 가치와 손실

- `INNER_LOOP_GAIN`: B와 A의 고유 결함·기전군·탐지 run이 같았다. 이 자료에서 구조 편집의 추가 탐지 이득은 관측하지 못했다.
- `REPLAY_GAIN`: 평가 I에서 C가 B의 미검출 상태 문제 3 run을 보완했다. 고유 결함은 B도 다른 seed에서 모두 발견했으므로 독립 결함 수 증가는 0이다. LOMO에서는 재생 자료가 해당 kind에 없어 이득이 없었다.
- `OUTER_TRANSFER_GAIN`: 평가 I에서 C/D 모두 30/30, 고유 작성 결함 10개·기전군 5개다. D는 C보다 최초 확인 호출이 적은 run 1개, 많은 run 0개였고 나머지는 같았다. 시간은 D가 빠른 run 17개·느린 run 13개였다. D의 전체 적용비는 C보다 0.508초(약 1.05%) 높았다. 호출 1개 사례의 이득을 종합 성공으로 승격하지 않는다.
- `NEGATIVE_TRANSFER`: C가 탐지하고 D가 미탐지한 run은 두 평가 모두 0이었다. 다만 LOMO 공동 탐지 27 run에서 D의 첫 확인 호출은 4개에서 감소·2개에서 증가했고, 시간은 9개에서 단축·18개에서 증가했다. D 총 적용비는 C보다 0.362초(약 0.73%) 높았다. LOMO의 차이는 학습 규칙이 적용된 효과가 아니라 fallback 경로의 차이다.
- 평가 I의 D는 학습 규칙으로 실제 후보 54개를 실행했고 확인 재현을 포함한 해당 경로의 호출은 78회였다. 사용 사실은 인과적 효용 증명이 아니다. LOMO의 학습 규칙 사용은 0회다.

타깃 이름·정답·평가자 전용 재현 입력에 따른 특례 분기는 없다. C/D는 같은 함수·스케줄러·총 예산·Oracle·계측·축소를 사용하고 D의 구조 슬롯에서 학습 provider만 바뀐다. Source 재생 최대20%·구조 최대30%는 호출 상한이며 보장된 탐지 능력이 아니다. 무효·중복·적용 불가는 기본 탐색으로 반환했다.

## 독립성·정보·제품 경계

자료는 Source5·Target10·정상5의 한 작성 corpus다. 실제 프로젝트 독립성·다른 개발자 계보·과거 실제 결함의 고정 revision/수정 이력 최소 목표를 충족하지 못했다. 특히 직렬화 Source와 Target2는 상수를 생략한 정규화 AST가 같아 독립 구현으로 계산하면 안 된다. 다른 함수의 AST가 다르다는 사실도 계보 독립성의 증명은 아니다.

기존 EXACT/SUFFICIENT/NECESSARY/EMPIRICAL·UNKNOWN, R3 단일 생성/runtime/audit, MRI·CAST·Claim-to-Witness, E8 사용 장부·readiness를 보존했다. 새 프로파일은 타깃 내부 feedback만 허용하는 EXPERIMENTAL_PROBE이며 FINAL·발행·타깃 간 학습은 false다. 기존 R2/R3/R4의 부정적 결과·원본·태그·PyPI 수동 발행 경로는 변경하지 않았다.

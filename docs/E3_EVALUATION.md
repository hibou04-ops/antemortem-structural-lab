# E3 신규 통합 평가

E3는 유한한 정수 관계 문법 안에서 실패 제약을 학습하고, 계약과 변수 역할이 대응하는 새 대상의 입력 탐색에 재사용했습니다. 그러나 사전등록한 발견 수 증가 조건을 통과하지 못해 종합 판정은 `NO_IMPROVEMENT`입니다. 외부 프로그램에 대한 일반화 능력은 `GENERALIZATION_UNKNOWN`입니다.

## 평가 조건

- 기존 E1·E2 평가 자료를 사용하지 않은 신규 합성 개발 문제 3개와 최종 문제 8개를 사용했습니다.
- 공개 계약은 정수 덧셈·뺄셈·곱셈, `left`/`right` 역할, 입력 범위 `[-16,16]`입니다. 버그의 형태와 조건은 공개 명세에 넣지 않았습니다.
- 최종 문제는 동일한 실패 관계를 다른 변수 이름으로 표현한 3개, 실패 관계가 달라진 3개, 정상 대조군 2개입니다. 정상 대조군 하나는 계약 불일치를 검사합니다.
- `uniform`과 `mold` 각각 문제당 5개 seed, seed당 64개의 중복 없는 입력을 평가했습니다. 개발 1,920회와 최종 5,120회를 합쳐 후보 Oracle 호출은 7,040회입니다.
- 엔진과 평가 조건을 먼저 동결했습니다. 모든 최종 후보 5,120개를 동결한 뒤 Oracle을 실행했으며, 최종 결과를 생성기에 돌려주지 않았습니다.
- 개발 단계는 구조화된 실패 증거와 실패 가설의 반증을 전달합니다. 성공 점수·자연어 보상은 사용하지 않습니다.
- 생성기는 별도 프로세스와 공개 모듈만 복사한 임시 작업 폴더에서 실행했습니다. 이 로컬 평가의 격리 등급은 `LOGICAL_ISOLATION_ONLY`입니다. 같은 호스트 계정의 파일 접근을 차단했다는 뜻은 아닙니다.

## 최종 결과

| 지표 | Uniform | Mold |
| --- | ---: | ---: |
| 후보 Oracle 호출 | 2,560 | 2,560 |
| 주입 지점×seed 발견 합계 | 30 | 30 |
| seed 통합 고유 주입 지점 | 6 | 6 |
| 최초 발견까지 평균 호출 수 | 21.025 | 17.500 |
| 실패 입력 관측 횟수 | 452 | 1,104 |
| 평균 공간 엔트로피, 8×8 격자 | 5.265 | 5.008 |
| 최종 후보 생성 총 시간 | 6.316초 | 6.888초 |

최초 발견 평균은 정상 대조군과 미발견을 65로 처리한 40개 문제×seed 실행의 평균입니다. Mold의 평균 호출 수는 16.77% 작았지만, 실제 벽시계 실행 시간의 단축을 뜻하지 않습니다. 생성 시간은 프로세스 시작과 직렬화를 포함한 한 Windows 환경의 관측입니다. 비용 효율 우월성은 입증하지 않았습니다.

실패 입력 1,104개는 서로 다른 결함 1,104개가 아닙니다. 두 방법 모두 6개의 주입 지점을 발견했으며, 각 지점을 5개 seed에서 발견해 합계가 30입니다.

사전등록 성공 조건은 발견 합계가 최소 2회이면서 10% 이상 증가하고, 최초 발견 평균이 5% 이상 줄며, 정상 대조군과 계약 불일치 검사를 통과하는 것이었습니다. 발견 수 증가가 없으므로 일부 지표의 개선으로 종합 판정을 바꾸지 않았습니다.

## 실제 작동과 한계

- 계약이 일치하는 35개 실행에서 `APPLICABLE_FOR_PROBING`이 나왔고, 후보 순서는 기준선과 달랐습니다. 계약 불일치 5개 실행은 `UNKNOWN`으로 처리했으며 기준선과 같은 후보 순서를 사용했습니다.
- 최초 발견은 40쌍 중 23쌍에서 빨랐고, 15쌍에서 같았으며, 2쌍에서 늦었습니다. 모든 경우를 우월하게 만드는 전이는 아닙니다.
- 개발 Mold 15개 모두 남은 관계 가설이 원래 개발 문제의 유한 영역에서 정확한 실패 소속 관계와 일치했습니다. 이 검사는 평가 후 독립 수식으로 확인했습니다. 관측되지 않은 전역 영역의 인과 법칙을 증명한 결과는 아닙니다.
- 구조가 대응한다는 사실은 버그가 재발한다는 증거가 아닙니다. 계약이 일치하는 정상 대조군에도 탐색은 허용했지만, 독립 Oracle의 실패 관측은 0이었습니다.
- 변경된 모듈러 실패 관계의 한 대상에서는 Mold의 실패 관측이 기준선보다 적었습니다. 잘못된 prior의 비용을 완전히 없애지는 못했습니다.
- 임의 상태를 가진 프로그램, 자유 자연어 의미 해석, 자동 변수 의미 추론, 실제 오픈소스 결함 탐지 우월성은 이 평가로 검증하지 않았습니다.

## 검증과 재현 범위

별도 수식 감사는 생성기와 원래 Oracle 모듈을 import하지 않고 원시 7,040행의 입력·결과·주입 지점·예산·공간 지표를 다시 확인했습니다. 최종 후보 순서와 동결 파일 일치, 엔진과 원본 해시 보존도 통과했습니다. 추가 후보 Oracle 호출은 없었습니다.

공개 자료는 프로토콜 설명과 비식별 집계 결과입니다. 비공개 정답, 숨은 문제 소스, 원시 실행 기록은 공개 저장소와 배포 자산에 포함하지 않습니다. 공개 정보만으로 원시 평가 전체를 그대로 재실행할 수 있다는 주장은 하지 않습니다. 공개 제품 예제와 단위·통합 테스트는 별도로 실행할 수 있습니다.

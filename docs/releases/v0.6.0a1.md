# v0.6.0a1 (experimental)

공개 EFSM의 상태·행동·순서 관계를 E5 Version Space와 연결하고 native Hypothesis stateful 생성·축소, incremental Z3 witness와 frozen transfer를 실제 CLI로 제공합니다. 기존 E1~E5 결과·태그·코드 경계를 보존합니다.

**개발 연구 판정은 NO_IMPROVEMENT입니다.** E6 stateful 발견14/15 vs세 black-box15/15, E6/Hypothesis paired wall 중앙 비율2.514입니다. 독립 개발 traces320개에서 대표 temporal 가설13개 중12개가 반증됐습니다. 이를 연구 성능 향상으로 홍보하지 않습니다.

E5의 알려진 last-pop 기능 회귀는 표현·학습·전이되지만, 새 연구 source의 OUT_OF_GRAMMAR1건은 남아 해결 범위는 PARTIAL입니다. 외부 실제 프로젝트 일반화는 NOT_EXECUTED입니다. [최종 평가·한계](https://github.com/hibou04-ops/antemortem-structural-lab/blob/v0.6.0a1/docs/E6_EVALUATION_REPORT.md) · [공개 수치](https://github.com/hibou04-ops/antemortem-structural-lab/blob/v0.6.0a1/docs/E6_RESULTS.json).

- 같은 Version Space에서 경쟁 static/AST·temporal 관계를 반증·보존하며 실제 next query를 바꿉니다.
- Native RuleBasedStateMachine·rule·precondition·invariant·Bundle와 동결 뒤 shrinking·2회 독립 replay를 사용합니다.
- 수치 state 최대4개, 행동 최대16개, native 정수 인자 최대129값, trace min_size0/최대16단계입니다.

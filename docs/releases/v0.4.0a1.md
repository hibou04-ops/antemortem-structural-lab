# v0.4.0a1 — E4 Structural QA Integration

기존 Mold·Version Space에 Hypothesis 후보 검사·수치 반례 축소를 연결했습니다.
공개 AST 관계식, enum/Z3 일관성 검사, 구조 증거로 AST 후보를 제거하는 API,
Generator 전송 전 typed 검증과 동결 후 feedback 차단을 추가했습니다.
`pbt-demo`, `pbt-run`, `constraints-check`를 제공합니다.

기본 패키지는 표준 라이브러리만 사용합니다. PBT는 `qa`, Z3는 `solver` extra를 설치합니다.
패키지·가져오기·CLI 이름은 각각 `antemortem-structural-lab`, `tomolab`, `tomolab`입니다.
기존 MRI·CAST·Claim-to-Witness·Mold 명령을 보존하며 PyPI 게시를 포함하지 않습니다.

로컬 Python3.12 전체 **145 PASS**(기존76+신규69), sdist/wheel 빌드·메타데이터·공개 내용
검사를 통과했습니다. CI는6개 OS/Python 조합과 별도 Docker 경계를 검사하고 모두 성공한
main에서만 게시합니다. 별도 환경에서 기본·선택 의존성 wheel 설치를 검사하며 공개 자산을
다시 다운로드해 SHA-256을 확인합니다.

새 공개 순수 함수로 개발·최종 검증을 분리했습니다. 개발 후보48개·중복0, 반례
`(6,-7)` → `(3,0)`, Oracle39회, AST 가설4개 → 1개, enum/Z3 상태3/3 일치를 관측했습니다.
최종 함수별 동결 후보64개, feedback0회입니다. [측정 정의·제한](../E4_IMPLEMENTATION.md).

이는 기능·회귀 검증이며 최종 사례도 공개 합성으로 블라인드가 아닙니다.
외적 일반화·기존 도구 대비 우위는 **NOT_ESTABLISHED**입니다. E1/E2/E3 증거·태그·판정을
보존하며 비공개 평가 자료를 재사용·공개하지 않습니다. 두 정수·유한 계약만 지원하고
임의 Python 의미 추론·상태 있는 함수는 미지원입니다. 기본 subprocess는 OS 보안 격리를
제공하지 않으며 대상 함수 실행에는 신뢰가 필요합니다.

# v0.5.0a1 (experimental)

AST·Version Space·Active Learning·Hypothesis·Z3를 하나의 실행 가능한 구조적 discovery 루프로 연결했습니다. 기존 MRI·CAST·Claim-to-Witness·E4와 역사적 증거·태그는 보존합니다.

- typed 공개 AST guard가 실제 가설과 query를 바꾸고, 관측의 반증이 Version Space에 반영됩니다.
- native Hypothesis 복합 Strategy·fresh 후보·shrinking, 실제 선택되는 Z3 witness, 동결 typed/role/graph/contract 전이를 연결했습니다.
- finite int/float/str/list/tuple/dict와 제한된 state trace, 명시적 예외 계약을 제공합니다.
- `discovery-inspect/demo/run/plan`, 실제 CLI와 installed-wheel 검사, default logical / optional Docker 경계를 제공합니다.
- 로컬 **243 tests passed**, 기존 145개 회귀 포함. 원격 CI·public asset 결과는 이 릴리스의 main commit과 Actions에서 확인할 수 있습니다.

**개발 비교 NO_IMPROVEMENT**: E5와 native Hypothesis 모두 다섯 mutation 계열을 찾았지만, paired wall 중앙 비율 2.660 / 최초 발견 호출 비율 1.0으로 비용 개선 기준을 만족하지 못했습니다. 발견률 포화나 테스트 수 증가를 연구 성능 향상으로 취급하지 않습니다. 440개 개발 입력에서 대표 후보 5개 중 2개가 반증됐으며 전이 gate 28/28은 정적 대응 검사일 뿐 결함 재현 성능이 아닙니다.

최종 검증은 새로 작성한 비공개 사례와 frozen source molds를 이용한 once-only 평가입니다. 결과·hash·지원 한계는 [E5 평가 기록](https://github.com/hibou04-ops/antemortem-structural-lab/blob/v0.5.0a1/docs/E5_INTEGRATION.md)과 [공개 aggregate](https://github.com/hibou04-ops/antemortem-structural-lab/blob/v0.5.0a1/docs/E5_RESULTS.json)에 기록합니다. 외부 실제 프로젝트 일반화는 **NOT_EXECUTED / 미입증**이며 SOTA·보편적 우월성을 주장하지 않습니다.

Generator는 공개 명세·승인된 개발 IR·최소 증거만 받습니다. 기본 subprocess는 LOGICAL_ISOLATION_ONLY, 선택적 Docker는 생성기 정보 접근을 제한합니다. 대상·Oracle은 신뢰된 호스트 코드입니다. 임의 코드의 보안 실행이나 전체 프로그램 의미 증명이 아닙니다.

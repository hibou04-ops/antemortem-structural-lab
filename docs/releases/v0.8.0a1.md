# v0.8.0a1 — Experimental function testing and evidence replay

Antemortem Structural Lab is an **experimental verification tool**, not a universal Oracle or a proof of program correctness. This prerelease makes the reviewed-function → explicit JSON contract and Oracle → bounded search receipt → evidence replay path the main product entry point.

```bash
python -m pip install "antemortem-structural-lab[qa]==0.8.0a1"
python -m tomolab --help
python -m tomolab online-demo --workspace demo-work --usage-ledger demo-usage.jsonl --allow-local-execution --budget 24 --shrink-budget 6 --output demo-result.json
```

## Product changes

- **A is the default** online policy. A/B demos use a small authored integer fixture without Source collection or learning. B/C remain optional; D requires explicit experimental opt-in and a reviewed Source Mold.
- `online-run` accepts a reviewed synchronous Target and Oracle, each taking one supported JSON value. New receipts bind the source files and input contract.
- `online-replay` verifies those bindings and reproduces stored failures without performing a new search. Legacy receipts require explicit unbound compatibility opt-in.
- The installed wheel and source distribution include the new product example. English and Korean READMEs provide the same commands and facts; migration and third-party notices clarify the preserved historical interfaces and original licenses.

`CONFIRMED_FAILURE` means a Target/Oracle disagreement reproduced, subject to the supplied contract and Oracle. `NO_CONFIRMED_FAILURE_WITHIN_BUDGET` is a search miss, **not a correctness proof**. Unknown results, errors, limits, and replay mismatches remain inconclusive. Shrinking does not prove global minimality.

## Research conclusions are preserved

The frozen 384-run E9-R1 study used known historical defects from three projects. In implementation transfer A/B/C/D all rediscovered 5/6 defects; **D had no detection or first-confirmation query gain over C**. In eligible empty-input leave-one-mechanism-out runs D detected 0/6 at both budgets despite using learned rules. C detected 4/6 at budget 24 and 6/6 at 48; A/B detected 6/6 at both. C also lost detections against A/B at the smaller budget.

This includes observed negative transfer. Tool publication does not establish external generalization, independent corroboration, new defects in current upstream versions, or final-evaluation readiness. The existing research profiles and their `allow_release=false` records remain unchanged; explicit authorization covers this experimental product publication only. Research cohorts were not rerun to improve these results.

## Boundaries and immutable files

Local execution imports and calls trusted Python on the host. `--allow-local-execution` is consent, not an OS sandbox. Reviewed external historical capsules retain their separate inspected container gate. Pure functions or reviewed full-trace reset adapters are required; arbitrary hostile code and hidden persistent state are unsupported.

The publication workflow builds one final distribution set, checks it, installs that exact wheel and sdist outside the checkout, and shares those files between GitHub and PyPI. CI's earlier preflight build is separate. Existing versions and tags, including PyPI `0.7.0a1`, are not replaced. Project code remains Apache-2.0; historical extracts retain their MIT/BSD notices. No raw private research archives, credentials, or private keys are release assets.

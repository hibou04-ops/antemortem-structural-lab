# v0.7.0a1 (experimental)

**연구 판정은 INCONCLUSIVE입니다.** 새 동결 최종 비교72건은 54 COMPLETE·18 Stateful NOT_COMPARABLE, 필수 방법 오류·시간 초과·대조군 오탐·Generator feedback0입니다. Native Hypothesis·E6·E7 모두 발견0, 주평가 qualified/guided0이므로 구조적 지식의 추가 가치와 외적 일반화는 입증하지 못했습니다. 비교 범위는 최대64개 동결 계획이며 전체 적응형 PBT 우월성 검증이 아닙니다.

개발 v1은 Oracle 정밀도 오류로 `INVALID_ORACLE / INCONCLUSIVE` 처리하고 원본127개 파일을 보존했습니다. 독립 감사는 이미 기록된 개발 불일치6회 중 실제 소스 불일치2회와 Oracle 오판4회를 구분했습니다. 정확 산술 Oracle를 독립 검토하고 v2 계약을 최종 관측 전에 재등록했습니다. 개발 재검증은 새 블라인드 평가로 세지 않습니다.

실패 로그의 구조적 가설·지지·반증·적용 범위를 보존하는 Evidence-Gated Structural Knowledge를 추가했습니다. 기존 E5/E6 엔진과 Hypothesis·Z3를 재사용하며 실제 자격을 얻은 관계만 제한된 후보 선택에 사용합니다.

- 동일한 별도 검토 구현의 positive/negative 개발 증거, typed 역할·연산·상태/승인된 공개 IR 계약으로 적용을 판단합니다. 호스트의 출처 확인과 해시 일치는 의미적 독립성·원인의 증명이 아닙니다.
- 자격 있는 지식이 없으면 worker·pool·solver 없이 native Hypothesis를 실행합니다. guidance는 전체 계획 예산의 최대 절반으로 제한하고 native 탐색 경로를 유지합니다. 유한 도메인이 소진되면 실제 후보 비율은 달라집니다. 동결 뒤 native search/shrink·독립 replay를 수행합니다.
- append-only 기록과 과거 snapshot 복귀 차단, 전체 부모 기록을 보존하는 명시적 새 개발 세대, 캐시 입력 경합·재해시 조작 방어를 추가했습니다. 최종 피드백은 새 세대에서도 허용하지 않습니다.
- `knowledge-inspect/learn/update/plan/run/demo`, Python 3.11~3.13 CI와 별도 E7 Docker 접근 통제를 제공합니다. 기본 subprocess는 LOGICAL_ISOLATION_ONLY, 대상/Oracle는 신뢰된 호스트 코드입니다.

실제 사용자 소유5개 프로젝트의 원본 순수 함수9개를 개발3/최종6으로 나눈 새 평가 계약을 사용합니다. 실제 대상 코드를 mutation으로 바꾸지 않으며 함수·프로젝트·실패 메커니즘의 수를 구분합니다. 결과 관측 전 수학·문서상 Oracle 권한과 preconditions를 독립 검토합니다. 개발/최종 실제 판정은 [평가 보고서](https://github.com/hibou04-ops/antemortem-structural-lab/blob/v0.7.0a1/docs/E7_EVALUATION_REPORT.md)와 [공개 집계](https://github.com/hibou04-ops/antemortem-structural-lab/blob/v0.7.0a1/docs/E7_RESULTS.json)에 기록합니다.

동봉된 directed-width 예제는 공개 참조 모델을 사용하는 작성된 기능 fixture입니다. 그 전이 성공·테스트 수·동결 재개 기능을 실제 프로젝트의 추가 발견이나 자기개선 효과로 승격하지 않습니다. 자동적인 임의 프로그램의 의미 대응 학습이나 버전 간 동일 engine snapshot 재생도 보장하지 않습니다.

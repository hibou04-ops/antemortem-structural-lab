# v0.1.1 — optional TypeSafe Jev provider

**Pre-release / retrospective snapshot import.** Adds a direct TypeSafe API integration next to the existing Vercel provider, with explicit provider selection and no cross-provider billable fallback. Mock/provider tests cover response/transport handling (29 unit tests in the import environment). The original archived `pyproject.toml` mistakenly still declared `0.1.0`; a visible, packaging-only public import commit corrected this to `0.1.1` before tagging.

**Limitations:** Jev does not verify correctness and predictive benefit has not been benchmarked. Live connectivity demonstrated separately in a user-controlled environment is not represented by a secret or credential here. Running the included smoke script may consume paid API credits.

Publication checks rebuilt the wheel from this unchanged tag and reran all 29 tests. Its runtime modules match the original release-kit wheel. This historical wheel does not bundle demonstration fixtures: use the attached source ZIP and pass its example path to `tomolab run`. Generate fresh evidence before replaying; archived generated outputs were excluded. For the edited bilingual entry point and self-contained wheel demonstrations, use v0.2.0.

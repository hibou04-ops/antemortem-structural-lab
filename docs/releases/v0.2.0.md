# v0.2.0 — Phase C0: claim-to-witness

**Pre-release / retrospective snapshot import with public documentation cleanup.** Adds no-reference-function metamorphic checks for six exact claim sentence templates, three relation types, stored witnesses and claim replay; 45 unit tests in this environment.

CrossHair can independently find the same three toy violations when given the relation asserts. The toy 90/90 feedback result is deliberately nonblind and not evidence of competitive superiority.

**Not included:** open-ended claim parsing, evaluation of natural-language semantic fidelity, a trusted universal verifier, production safety guarantees, paid Jev performance testing.

*Import disclosure:* the source originates in archived experimental snapshots. Private data and outputs containing local filesystem paths were omitted. Public user-facing documentation was refined before tagging; this tag is not byte-identical to the private ZIP artifact.

Before first publication, the English and Korean READMEs were edited against the source. A Windows test now reads the generated UTF-8 evidence explicitly. The wheel includes the bundled examples and locates them after installation outside the source checkout; the underlying probe and claim algorithms are unchanged. Package metadata includes the final English README, and both READMEs are included as distribution data. CI checks the source build and a fresh wheel installation.

The unpublished original v0.2.0 tag object and commit are disclosed in PUBLIC_IMPORT_NOTICE.md. All prior commits remain in the history, and the v0.1.0/v0.1.1 tag objects are preserved.

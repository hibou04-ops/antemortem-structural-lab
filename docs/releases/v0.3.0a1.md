# v0.3.0a1 — Integrated Mold engine (experimental)

실패 증거로 경쟁 가설을 줄이고 다음 입력을 선택하는 Mold 엔진을 기존 `tomolab`에 통합한 사전 릴리스입니다. MRI·CAST·Claim-to-Witness와 선택적 Jev 연결은 유지합니다.

## 새로운 기능

- 유한 정수 영역에서 typed structural relation과 version space를 관리합니다.
- CEGIS 방식으로 반증된 가설을 제거하고, 남은 가설의 불일치와 공간 다양성을 다음 입력 선택에 사용합니다.
- 제약마다 출처, 지지 반례, 반증, 경쟁 가설, 범위, 버전과 불확실성을 남깁니다.
- 역할 대응과 명시된 연산·불변식·계약을 검사해 `APPLICABLE_FOR_PROBING` 또는 `UNKNOWN`으로 구분합니다.
- 기본 bounded enumeration과 선택적 Z3를 지원합니다.
- `mold-demo`, `mold-run`, 동결 상태의 `mold-plan` CLI와 별도 Generator 실행 경계를 제공합니다.
- 한국어 README를 사용·설치·결과 해석 중심으로 개정하고 영어 README와 기술적 사실을 맞췄습니다.

## 검증 상태

Windows·Python 3.12.10에서 기존·신규 테스트 **76개**가 통과했습니다. wheel·sdist를 빌드했고, 소스 밖의 새 설치 환경에서 기존 CLI와 Mold·전이 계획을 실행했습니다. 한국어·영어 README의 실제 CLI 명령 **14개**도 별도 공개소스 복사본에서 통과했습니다. CI·Docker 접근 통제·최종 공개 자산 검증은 별도 발행 조건이며 실제 [Actions](https://github.com/hibou04-ops/antemortem-structural-lab/actions)와 [검증 기록](../RELEASE_VALIDATION.md)에서 확인해야 합니다.

새 독립 합성 평가의 후보 호출은 **7,040회**입니다. 최종 uniform/Mold 발견 합계는 **30/30**, 고유 주입 지점은 **6/6**이었습니다. 첫 발견 평균은 **21.025/17.5** 호출(미발견 65 처리)이었지만 발견 범위 증가가 없어 사전 판정은 **`NO_IMPROVEMENT`**, 일반화는 **`GENERALIZATION_UNKNOWN`**입니다. 반복 실패 입력 452/1,104를 독립 결함 수로 해석하지 않습니다. 원시 기록 7,040행의 별도 감사와 엔진 10개 파일의 동결 해시 검사를 통과했습니다. [평가 조건과 집계](../E3_EVALUATION.md)를 참고하세요.

E1은 `E1_EXECUTED_NO_IMPROVEMENT`, E2는 `E2_EXECUTED_NO_IMPROVEMENT`를 유지합니다. E2에서 D와 A는 동일했고 새로운 portable constraint는 0개였습니다. E3 결과는 이전 평가 자료와 분리하며 실제 검증 범위 밖의 일반화·성능 우월성을 주장하지 않습니다.

## 알려진 제한

- 정수 입력 두 개·정수 출력의 순수하고 결정적인 함수, 최대 4,225개 입력 영역과 고정 관계식 grammar를 지원합니다. 임의의 상태 전이·부작용·자연어 의미 복원은 지원하지 않습니다.
- 적용 계약 일치는 탐색 허용 근거이며 같은 버그의 존재나 전이 정확성의 증명이 아닙니다.
- 기본 subprocess는 `LOGICAL_ISOLATION_ONLY`입니다. 선택적 Docker는 Generator의 파일·네트워크·권한 경계이며 대상/Oracle을 적대적 코드로부터 격리하는 기능이 아닙니다.
- `--allow-local-execution`은 동의 표시입니다. 검토한 신뢰 코드만 실행하세요.
- C1 연구 PR은 이 릴리스에 자동 병합하지 않습니다. 기존 v0.1.0, v0.1.1, v0.2.0 태그는 보존합니다.
